# DTO Patterns

DTOs (Data Transfer Objects) live in the **data layer** and handle JSON serialization + mapping to domain entities.

## Canonical Template — Response DTO

```dart
import 'package:flutter_template_v3/features/<feature>/domain/domain.dart';
import 'package:freezed_annotation/freezed_annotation.dart';

part '<entity>_dto.freezed.dart';
part '<entity>_dto.g.dart';

@freezed
abstract class EntityDto with _$EntityDto {
  const factory EntityDto({
    required String id,
    required String name,
  }) = _EntityDto;

  const EntityDto._();

  factory EntityDto.fromJson(Map<String, dynamic> json) =>
      _$EntityDtoFromJson(json);

  Entity toDomain() {
    return Entity(id: id, name: name);
  }
}
```

## Rules

1. **`@freezed abstract class XDto with _$XDto`** — Freezed 3.x
2. **Private constructor `const XDto._()`** — required for instance methods like `toDomain()`
3. **Both** `part '*.freezed.dart'` **AND** `part '*.g.dart'`
4. **`factory XDto.fromJson(Map<String, dynamic> json)`** — generated by json_serializable
5. **`Entity toDomain()`** — manual mapping to domain entity
6. **`@JsonKey(name: 'server_field')`** when API field names differ from Dart names
7. Private constructor goes **after** the `const factory`, **before** `fromJson`

## Real Examples

### UserDto

```dart
// lib/features/auth/data/models/user_dto.dart
import 'package:flutter_template_v3/features/auth/domain/domain.dart';
import 'package:freezed_annotation/freezed_annotation.dart';

part 'user_dto.freezed.dart';
part 'user_dto.g.dart';

@freezed
abstract class UserDto with _$UserDto {
  const factory UserDto({
    required String id,
    required String email,
    required String name,
    String? avatarUrl,
  }) = _UserDto;

  const UserDto._();

  factory UserDto.fromJson(Map<String, dynamic> json) =>
      _$UserDtoFromJson(json);

  User toDomain() {
    return User(id: id, email: email, name: name, avatarUrl: avatarUrl);
  }
}
```

### PostDto

```dart
// lib/features/home/data/models/post_dto.dart
import 'package:flutter_template_v3/features/home/domain/domain.dart';
import 'package:freezed_annotation/freezed_annotation.dart';

part 'post_dto.freezed.dart';
part 'post_dto.g.dart';

@freezed
abstract class PostDto with _$PostDto {
  const factory PostDto({
    required String id,
    required String title,
    required String body,
    required String authorId,
    required DateTime createdAt,
  }) = _PostDto;

  const PostDto._();

  factory PostDto.fromJson(Map<String, dynamic> json) =>
      _$PostDtoFromJson(json);

  Post toDomain() {
    return Post(
      id: id,
      title: title,
      body: body,
      authorId: authorId,
      createdAt: createdAt,
    );
  }
}
```

## Request DTO Template

Request DTOs have `toJson()` but **no `toDomain()`** — they go server-ward, not domain-ward.

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'sign_in_request.freezed.dart';
part 'sign_in_request.g.dart';

@freezed
abstract class SignInRequest with _$SignInRequest {
  const factory SignInRequest({
    required String email,
    required String password,
  }) = _SignInRequest;

  factory SignInRequest.fromJson(Map<String, dynamic> json) =>
      _$SignInRequestFromJson(json);
}
```

Note: Request DTOs don't need the private constructor (`const SignInRequest._()`) because they have no instance methods.

## @JsonKey Usage

```dart
@freezed
abstract class UserDto with _$UserDto {
  const factory UserDto({
    required String id,
    @JsonKey(name: 'full_name') required String fullName,
    @JsonKey(name: 'avatar_url') String? avatarUrl,
    @JsonKey(name: 'created_at') required DateTime createdAt,
  }) = _UserDto;

  // ...
}
```

## Barrel File

Add every new DTO to the sub-barrel `models/models.dart`:

```dart
// data/models/models.dart
export 'user_dto.dart';
export 'sign_in_request.dart';
```

Do NOT add individual files to the layer barrel `data.dart`.

## Anti-Patterns

```dart
// BAD: missing private constructor — toDomain() won't compile
@freezed
abstract class UserDto with _$UserDto {
  const factory UserDto({required String id}) = _UserDto;
  // no const UserDto._();
  User toDomain() => User(id: id);  // ERROR: instance method without private constructor
}

// BAD: returning entity from fromJson
factory UserDto.fromJson(Map<String, dynamic> json) {
  return User(...);  // WRONG — fromJson returns DTO, not entity
}

// BAD: missing part directives
// needs BOTH:
part 'user_dto.freezed.dart';
part 'user_dto.g.dart';

// BAD: DTO without toDomain() (for response DTOs)
// Every response DTO MUST have toDomain()

// BAD: using `class` instead of `abstract class`
@freezed
class UserDto with _$UserDto { ... }
```
